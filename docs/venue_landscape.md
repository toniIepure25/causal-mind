# Publication Venue Landscape

A landscape of plausible venues for the three papers, with fit, risk, and a recommendation.
Part of the `cm8-prehuman-v1.0` freeze. **No acceptance probability is claimed**; this is a
fit assessment only.

## Paper 1 — Predicting the Future of the Thought Stream (predictive dynamics)

- **Topic:** multi-horizon semantic forecasting of spontaneous thought; a measurable
  predictive horizon.
- **Fit:**
  - *Cognitive Science / Cognition* — strong fit (spontaneous thought + prediction).
  - *Journal of Experimental Psychology: Learning, Memory, and Cognition* — good fit
    (prediction, baselines, nulls).
  - *Neural Computation / PNAS* — possible if the horizon framing is emphasized (PNAS is
    competitive; the modest effect is a risk).
  - *Cognitive Science Society (CogSci)* — good fit for a conference version.
- **Risk:** the modest effect + small test set (n=17) is the main risk for a top journal.
- **Recommendation:** lead with the *horizon* and the *decay* (the qualitative result);
  target a cognitive-science journal; a CogSci conference version is a safe first venue.

## Paper 2 — From Prediction to Intervention (causal method + frozen design)

- **Topic:** a validated causal-inference method for the thought stream + a frozen,
  pre-human-hardened confirmatory design.
- **Fit:**
  - *Causal inference / methods venues* (e.g., a statistics or causal-inference workshop) —
    good fit for the *method* contribution.
  - *Cognitive Science* — good fit for the bridge (forecast → intervene).
  - *Preprint (arXiv)* — appropriate to establish priority before the human run.
- **Risk:** the confirmatory human result does not exist yet; the paper is a *method +
  design* paper, not a *result* paper. This must be framed clearly.
- **Recommendation:** frame as "method validation + frozen design"; an arXiv preprint to
  establish priority, then a methods/causal venue for the method contribution.

## Paper 3 — Break-the-Chain Protocol (protocol + result, after the run)

- **Topic:** the frozen confirmatory protocol and (after the run) its result.
- **Fit:**
  - *Protocol registration* (OSF / AsPredicted) — **do this before the run** (priority +
    transparency).
  - *Cognitive Science / JEP:LMC* — for the result (after the run).
  - *Nature Human Behaviour / PNAS* — only if the result is a positive, robust causal
    effect (high bar; the modest prediction effect and N=20 are risks).
- **Risk:** if the result is a null, the top venues are unlikely; a cognitive-science
  journal or a methods venue is the realistic target. A null is still publishable.
- **Recommendation:** register the protocol now (OSF/AsPredicted); after the run, target a
  cognitive-science journal regardless of sign (a null is a result).

## Cross-cutting notes

- **Preprint strategy:** arXiv preprints for Papers 1 and 2 establish priority and invite
  feedback before the human run.
- **Registration:** the CM-8 protocol should be registered (OSF/AsPredicted) **before** the
  confirmatory run (transparency + priority).
- **Data/code sharing:** the code + manifests are shareable now; the (pseudonymized,
  post-approval) analysis artifacts are shareable after ethics approval, per the GDPR plan.
- **No acceptance probability** is claimed anywhere; this is a fit assessment only.

## Recommendation (summary)

1. **Now:** arXiv preprint for Paper 1 (and Paper 2); register the CM-8 protocol
   (OSF/AsPredicted).
2. **After the run:** Paper 3 to a cognitive-science journal (regardless of sign).
3. **Methods:** the causal-method contribution (Paper 2) to a methods/causal venue.
