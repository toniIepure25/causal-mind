# Master's Thesis Timeline

A concrete timeline for the Master's thesis, anchored to the ethics deadline and the
confirmatory-run gate. Part of the `cm8-prehuman-v1.0` freeze. Dates are planning targets;
the ethics deadline is the hard constraint.

## Hard constraints

- **Ethics submission deadline:** 5 Oct 2026 (for the 5 Nov 2026 Ethics Committee meeting).
- **Ethics decision:** ~5 Nov 2026 (earliest; realistically later).
- **Pilot (CM-8P):** after ethics approval; ~2–4 weeks.
- **Confirmatory run (CM-8H):** after pilot GO; ~4–8 weeks (recruitment + data collection).

## Timeline (two scenarios)

### Scenario A — Ethics clears in time (the north star)

| when | milestone |
| --- | --- |
| **Now (Sep 2026)** | Pre-human freeze done (`cm8-prehuman-v1.0`); supervisor package ready. |
| **By 5 Oct 2026** | Supervisor sign-off + ethics submission (the hard deadline). |
| **~5 Nov 2026** | Ethics Committee meeting; decision (earliest). |
| **Dec 2026 – Jan 2027** | Pilot (CM-8P): 3–5 participants; operational GO/ITERATE/STOP. |
| **Jan – Mar 2027** | Confirmatory run (CM-8H): N=20, 24 trials; data collection. |
| **Mar – Apr 2027** | Analysis (pre-registered); result (positive or null). |
| **Apr – May 2027** | Thesis writing (Option A: the confirmatory experiment as capstone). |
| **May – Jun 2027** | Thesis finalization + defense preparation. |
| **Jun 2027** | Defense (target). |

### Scenario B — Ethics slips or the pilot stops (the guaranteed floor)

| when | milestone |
| --- | --- |
| **Now (Sep 2026)** | Pre-human freeze done; supervisor package ready. |
| **Sep – Oct 2026** | Thesis writing begins on **Option B** (forecast → explain → intervene method;
  all results already done and pushed). |
| **Oct – Dec 2026** | Thesis draft (Papers 1–2 content + the negative results + the validated
  method). |
| **Dec 2026 – Feb 2027** | Revision + red-team + reviewer-response preparation. |
| **Feb – Mar 2027** | Thesis finalization + defense preparation. |
| **Mar – Apr 2027** | Defense (target). |

*In Scenario B, if ethics later clears, the confirmatory result can be added as an
appendix / follow-up without changing the defended thesis.*

## What is common to both scenarios

- The pre-human freeze `cm8-prehuman-v1.0` and its hashes.
- The claim-level evidence matrix and the honest treatment of every negative result.
- The three papers (Paper 1 ready now; Paper 2 ready now; Paper 3 after the run).
- No free-will claim; no overclaiming; no change to the frozen protocol.

## Critical path

The **ethics submission (5 Oct 2026)** is the single critical path. If it is met, Scenario A
is available; if not, Scenario B is the guaranteed, defensible floor. **Action:** get
supervisor sign-off and submit the ethics application **before 5 Oct 2026**.

## Risk register

| risk | impact | mitigation |
| --- | --- | --- |
| Ethics slips past 5 Oct | Scenario A capstone delayed | Scenario B floor (complete today) |
| Pilot stops (operational) | No confirmatory run | Scenario B floor; a stop is a valid outcome |
| Confirmatory run is a null | No positive causal result | A null is a result; Scenario B floor stands |
| Recruitment is slow (N=20) | Confirmatory run delayed | The power surface documents the under-power; do not change the protocol |
| Defense date is fixed early | Scenario A infeasible | Scenario B floor |
